# Vale project vocabulary. One pattern per line; # starts a comment.
#
# A bare literal makes Vale.Terms enforce that exact capitalization wherever
# the word appears, so a name worth spelling one way — a product, project,
# person, or acronym — is a literal. An ordinary noun has no capitalization to
# enforce, and a case-sensitive one flags its own sentence-initial capital at
# error severity, so it takes (?i) and folds its inflections into one pattern:
# (?i)repos?, not repo alongside repos.
#
# Every entry appears in the linted set (README.md and docs/). A term the
# repository uses only outside that set is re-added on its first documented use.
