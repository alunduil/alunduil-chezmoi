# Credentials

Every credential on a `workstation` host: where it comes from, which
[data flow](data-flow.md#level-0) store holds it, which process reads it,
and what it reaches. That includes the credentials of every Model
Context Protocol (MCP) server a Claude Code session calls. Process and
store numbers are the Level 0 ones.

| Credential | Source | Held in | Read by | Reaches |
| --- | --- | --- | --- | --- |
| 1Password account password | The user | Not stored | `2.0` | 1Password |
| 1Password Secret Key | The user, at first sign-in | The 1Password app | `2.0` | 1Password |
| age identity | The user, by hand at bootstrap | D2 | `1.0` | None |
| SSH key | 1Password | D4 | `2.0`, signing for `4.0` | GitHub, Home Assistant |
| GitHub token | 1Password | D3, D5 | `1.0`, `3.0` | GitHub |
| TrueNAS API key | 1Password | D3, D5 | `1.0`, `3.0` | TrueNAS appliance |
| Uptime Robot token | 1Password | D3, D5 | `1.0`, `3.0`, `4.0` | Uptime Robot |
| Codecov token | 1Password | D3 | `4.0` | Codecov |
| Grafana Cloud token | 1Password | D3 | `5.0` | Grafana Cloud |
| Cloudflare token | age-encrypted in D1 | D3 | `4.0` | None drawn |
| Claude Code session | `claude` login, from Anthropic | D9 | `3.0` | Anthropic |
| Cloudflare MCP OAuth grants | Browser sign-in on first use, from Cloudflare | D9 | `3.0` | Cloudflare |
| `gh` OAuth token | `gh auth login`, from GitHub | D9 | `4.0`, `7.0`, `9.0` | GitHub |
| Tailscale node key | Generated by `8.0` | D11 | `8.0` | Tailscale coordination server, peers on the tailnet |
| Grafana Cloud login | `gcx login` | D9 | `gcx` | Grafana Cloud |
| Readwise token | `readwise login` | D9 | `readwise` | Readwise |
| Keybase device keys | `keybase login` | D9 | `keybase` | Keybase |
| Signal registration | `signal-cli register`, Signal Desktop link | D9 | `signal-cli`, Signal Desktop | Signal |

## Servers a session calls

| Server | Credential | Held in |
| --- | --- | --- |
| Notion and Readwise, through claude.ai connectors | OAuth grant on the Anthropic account | Anthropic |
| Cloudflare `dns-analytics` and `graphql` | OAuth grant | D9 |
| Cloudflare `docs` | None | Not applicable |
| GitHub, Uptime Robot | Bearer token | D5 |
| TrueNAS | API key as an environment variable | D5 |
| Context7 | None | Not applicable |

TrueNAS runs with certificate verification off.

## Shell environment

`dot_bashrc` exports the Codecov, Uptime Robot, and Cloudflare tokens
from D3 in every interactive shell. Every process that shell starts
inherits them, including a Claude Code session started from it, the
session's hooks, and the TrueNAS MCP server the session runs. Nothing
this repository manages reads the Cloudflare token.

## Unattended use

`7.0` and `9.0` spend the `gh` OAuth token with no person present. `7.0`
runs hourly and weekly timers, and `9.0` polls every 60 seconds while
Zellij runs.

## Login credentials

Apply never writes D9. A new host repeats each login by hand.
